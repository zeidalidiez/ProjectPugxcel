# Project Pugxcel (Antigravity) — Balancing Guidelines

## Philosophy
This is a **binary pass/fail** talent-tree roguelite. The fantasy is 'build-crafting' under pressure. Every run should feel fair but tense.

## Success Rate Targets
- Turns 1-3: 65–75% success rate (challenging but achievable)
- Turns 4-8: 45–65% (rising tension as threshold grows)
- Turns 9+: 75–95% for strong builds (god-run payoff)

## Current Threshold Formula
`threshold = 20 * (1.18 ** (turn-1))`
Bosses (every 5 turns): ×1.5 multiplier
